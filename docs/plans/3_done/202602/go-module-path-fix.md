## 概要

<!--

Go 版のモジュールパスを正しいパス（`github.com/mewstcom/mewst/go`）に修正するリファクタリング作業です。

**目的**:

- Go のモノレポにおける標準的な慣例に準拠する
- 外部からの `go get` コマンドが正しく動作するようにする
- ファイル構造とモジュールパスの一貫性を確保する

**背景**:

- 現在のモジュールパスは `github.com/mewstcom/mewst` だが、Go コードは `/go/` サブディレクトリに配置されている
- モノレポにおいて、サブディレクトリの Go プロジェクトはモジュールパスにサブディレクトリを含めるのが標準的な慣例
- `.golangci.yml` の depguard ルールが `/go` を含むパスで定義されていたが、現状のモジュールパスと合わなかったため修正が必要だった

### 変更対象ファイル

#### 1. go.mod

```diff
- module github.com/mewstcom/mewst
+ module github.com/mewstcom/mewst/go
```

#### 2. 全 Go ソースファイルのインポート文

```diff
- import "github.com/mewstcom/mewst/internal/handler"
+ import "github.com/mewstcom/mewst/go/internal/handler"
```

対象パッケージ:

- `github.com/mewstcom/mewst/internal/...` → `github.com/mewstcom/mewst/go/internal/...`

#### 3. .golangci.yml

depguard ルールのパッケージパスを元に戻す:

```diff
- pkg: github.com/mewstcom/mewst/internal/query
+ pkg: github.com/mewstcom/mewst/go/internal/query
```

goimports の local-prefixes:

```diff
- - github.com/mewstcom/mewst/go
+ - github.com/mewstcom/mewst/go
```

（現状のままで正しい）

### 実装方針

1. **一括置換**: `sed` や IDE のリファクタリング機能を使用して一括置換
2. **検証**: `go build ./...`、`go test ./...`、`make lint` で動作確認
3. **単一コミット**: 全変更を 1 つのコミットにまとめる（途中で壊れた状態を避けるため）

### 影響範囲の見積もり

```bash
# インポート文の数を確認
grep -r "github.com/mewstcom/mewst/internal" --include="*.go" | wc -l
```
