**問題点・改善提案**:

- **ドキュメント間の整合性**: 3層アーキテクチャの図で `Email` が Presentation 層に含まれていない

  `go/docs/architecture-guide.md` では Presentation 層に `Handler, Worker, Email` と明記されているが、`go/CLAUDE.md` の図では `Email` が省略されている。また、パッケージ一覧では `internal/email` が Presentation 層として記載されている（`go/CLAUDE.md:103` 付近）ため、図との不整合が生じている。

  ```
  # go/CLAUDE.md（現状）
  │ Presentation層                                          │
  │ - Handler, Worker, Validator, ViewModel, Template,    │
  │   Middleware                                           │

  # go/docs/architecture-guide.md（現状）
  │ Presentation層（プレゼンテーション層）                    │
  │ - Handler, Worker, Email                               │
  │ - Validator                                            │
  │ - ViewModel                                            │
  │ - Template                                             │
  │ - Middleware                                           │
  ```

  **修正案**:

  `go/CLAUDE.md` の図に `Email` を追加する：

  ```
  │ Presentation層                                          │
  │ - Handler, Worker, Validator, ViewModel, Template,    │
  │   Middleware, Email                                    │
  ```
