- **ヘルパー関数**: `AsValidationError` / `AsAppError` が提供されており、Handler での `errors.As` パターンが簡潔に書ける
- **nil レシーバーの安全性**: `HasErrors`, `HasFieldError`, `GetFieldErrors`, `FieldErrors` がすべて nil レシーバーに対応
- **コンパイル時チェック**: `var _ error = (*model.ValidationError)(nil)` による `error` インターフェース実装保証
- **テストの網羅性**: 正常系・異常系・nil レシーバー・ラップされたエラー・定数の一意性をすべてカバー（429行）
- **コメントの品質**: 日本語で意図を説明し、自明なコメントを避けている
