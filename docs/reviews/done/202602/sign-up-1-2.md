**種別**: 推奨

**背景**:

テストコードには正常系のテストが充実していますが、重複するメールアドレスやアットネームでの登録エラーのテストがありません。これらのチェックはバリデーション層（Handler層）で行われる設計でしょうか？

**選択肢**:

- [ ] はい、バリデーション層で重複チェックを行うため、Usecaseでのテストは不要
- [ ] いいえ、異常系テストを追加する予定
- [x] その他（下の回答欄に記入）

**回答**:

```
バリデーション層で行うので対応は不要です。
ただしバリデーション層を実装するときに漏れがなくなるようにするため、
設計書に異常系のテストも行うことを明記してください

それと「テストのセットアップが繰り返されている」についてですが、
テーブル駆動テストへのリファクタリングをお願いします。

```
