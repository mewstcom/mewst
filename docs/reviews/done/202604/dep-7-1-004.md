4. **エラー型（`ValidationError`, `AppError`）の使い分けを追記** → ✅ `architecture-guide.md` に「エラー型」セクションが新設され、`ValidationError` / `AppError` / 素の `error` の使い分け表、構造体定義、ヘルパー関数が記載されている
